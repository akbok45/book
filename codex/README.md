# Codex

The story bible. Anything the book treats as established fact lives here so it
can be checked rather than remembered.

- `characters.md` who they are, what they want, how they speak
- `places.md` settings and geography
- `timeline.md` what happens when, in story order
- `rules.md` how the world works, and what it explicitly cannot do
- `glossary.md` invented terms, names, spellings

Update these in the same change that establishes the fact in the manuscript.
