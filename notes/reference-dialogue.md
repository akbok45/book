# Dialogue references: Arrow, Assassin's Creed II, Black Flag

2026-11-16. Links to the full transcripts and dialogue at their sources, for
studying how these stories handle banter between brothers and friends. The
full texts are not copied here: they are copyrighted, so this file keeps the
links and short notes instead. Open a link to read the whole scene.

Arrow episode scripts are on Springfield! Springfield!. Game dialogue is on the
fan Assassin's Creed Wiki, where each memory page has a Dialogue section. Some
wiki pages are incomplete, and a few memory names may need the wiki's search
if a link lands on a disambiguation page.

## Scenes already used or suggested

- **Assassin's Creed II, "Sibling Rivalry"** (Sequence 1). Ezio and Federico
  race to the top of a church for nothing. Model for the brothers competing
  over an ordinary job: the last orange in 5.1.
- **Arrow, season 2, episode 1, "City of Heroes."** Oliver plays along with
  Felicity's joke, then tells her plainly he is glad to see her. Model for an
  honest line after the laugh: "So did I" in 4.4.
- **Black Flag** as a whole: Edward Kenway is the model for Crumble's plain
  stock (see the bible).
